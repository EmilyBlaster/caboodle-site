# caboodle-site

Source for the live marketing site at **https://caboodledesign.info**.

Static HTML, CSS, and JS. No build step. Deployed on Netlify (auto-deploys on push to `main`).

**If something breaks, or you need to run, deploy, or rebuild the site, read [RECOVERY.md](RECOVERY.md).** It covers local dev, deploy, the cache-version rule, the custom font, the field-reel video project, the domain, and the accounts you need.

Run locally:

```
npx serve .
```

# STACK

_Codebase map — generated 2026-05-16_

The Caboodle Design marketing site is a **no-build static website**. There is
no package.json, no bundler, and no compile step. Netlify deploys the repo
root as-is. Everything ships as hand-authored HTML, CSS, and JS.

## Languages & runtime

- **HTML5** — one file per page (`index.html`, `about.html`, `approach.html`,
  `work.html`, `contact.html`, `resources.html`, `labs.html`,
  `field-notes.html`, `contact-thanks.html`, plus `work/*.html` and
  `labs/*.html` sub-pages).
- **CSS3** — single global stylesheet `styles.css` (~7,300 lines). No
  preprocessor; plain CSS with custom properties.
- **JavaScript (ES, vanilla)** — single global script `script.js`
  (~1,400 lines). No framework, no transpiler. Loaded with
  `<script src="script.js?v=20260516" defer>`; the `?v=` query string is the
  manual cache-bust.
- **Python 3** — one utility script, `scripts/fetch-thumbnail.py`, used
  offline to pull TikTok thumbnails into `assets/tiktok/`. Not part of the
  deploy or runtime.

## Frameworks & libraries

- **No frontend framework.** No React/Vue/Svelte. All interactivity
  (scroll-driven field log, case-study iframe previews, the field guide bot)
  is vanilla DOM code in `script.js`.
- **Three.js `0.167.0`** — loaded only by `assets/3d/fire-extinguisher.html`
  via an ES-module `<script type="importmap">` from
  `cdn.jsdelivr.net/npm/three@0.167.0/`. Pulls `three.module.js`,
  `GLTFLoader`, and `OrbitControls`. Renders the interactive fire
  extinguisher (model at `assets/3d/fire_extinguisher.glb`). This is the only
  CDN-loaded JS library on the site.

## Build tooling & config files

- `netlify.toml` — deploy config. `publish = "."` (no build command).
  Netlify-side asset processing enabled: CSS bundle+minify, JS minify,
  HTML `pretty_urls`, image compression.
- `_headers` — Netlify cache-control and security headers. Fonts/assets get
  1-year `immutable` caching; CSS/JS/HTML get `max-age=0, must-revalidate`.
  Security headers (`X-Content-Type-Options`, `X-Frame-Options`,
  `Referrer-Policy`, `Permissions-Policy`) apply site-wide.
- `_redirects` — not present. No redirect rules.
- `.netlify/netlify.toml` + `.netlify/state.json` — generated by Netlify CLI
  link; `state.json` holds `siteId 36c119e8-865e-4eba-8dd1-7f548376db1f`.
  `.netlify/` is gitignored.
- `.claude/launch.json` — local dev: `npx serve .` on port 4322 (autoPort).
- `serve.sh` — local dev server. Prefers `npx live-server` (auto-reload on
  port 8080), falls back to `python3 -m http.server`.
- `.gitignore` — excludes OS noise, `.claude/`, `.netlify/`, `node_modules/`,
  reference folders, asset backups, and env files.
- `.githooks/pre-push` — repo-local git hook.

## No dependency manifest

There is no `package.json`, `node_modules/`, or lockfile. `npx` is invoked
ad hoc by `serve.sh` and `launch.json` to fetch a dev server on demand;
nothing is installed into the repo. The site has zero runtime npm
dependencies — all third-party code is either CDN-loaded (Three.js, Google
Fonts) or embedded via iframe (Vimeo, YouTube).
